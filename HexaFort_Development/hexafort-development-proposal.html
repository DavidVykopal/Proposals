HexaFort · Development proposal

Levný release test s jasným capem.

HexaFort beru jako rychlé dotažení research buildu, který kombinuje osvědčené jádro Hexapolis a novější meta/monetizační směr z Mecha Fortress. Cíl není plný reskin ani velký nový projekt. Cíl je dostat validovatelný release do store pipeline během jednoho kalendářního týdne, pokud MKT nepotvrdí riziko kanibalizace Hexapolis.

Product frame

Hexapolis core + Mecha Fortress meta

Projekt stojí na tom, že Hexapolis už prokázal silný základ, zatímco Mecha Fortress přinesl novější meta a monetizační vrstvu. HexaFort má ověřit, jestli se dá tento meta twist přenést na jiný gameplay bez velké přestavby a bez drahého art scope.

Must-have pro release test

  • Aktuální build, interní playtest a detailní scope lock po playtestu.
  • Lehký code polish, fixy release blockerů a sync vybraných MF monetizačních prvků včetně permanent VIP.
  • Odstranění placeholderů a nejviditelnějších rough edges v UI.
  • Setup IAPs, lokalizace, external links, prerelease checklist a build pipeline.
  • QA smoke test, store readiness, analytika, ASO texty/obrázky a základní kampaňové kreativy.

Vědomě mimo scope

  • Plný reskin z původní UI tabulky na úrovni 21.4 MD.
  • Kompletní redesign všech window, offerů, buildingů, hrdinů, popisků a avatarů.
  • Nový dlouhodobý content plan, pokud playtest neukáže jasnou potřebu.
  • Feature polish, který není nutný pro store release ani měření retention/ROAS signálu.
  • Rozšiřování kampaně nad UA cap bez výkonového signálu a nového souhlasu.

Execution window
