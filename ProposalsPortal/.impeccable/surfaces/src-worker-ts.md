# Surface brief: proposals portal (all routes)

Mode: Read (document pages), Operate (comment flow). Code-led.
Audience: NOXGAMES leadership + founders; live meeting on a shared screen and async review on laptop/phone.
Job: read the end-of-year proposals, leave feedback on exact passages, see others' feedback.

## Direction contract

THESIS: A leadership board pack, not a wiki. Numbered divider tabs, each document set as a page, feedback written as marginalia beside the passage it is about. Refuses the left-tree-sidebar wiki and the Google Docs clone.

OWN-WORLD: Q4 kickoff system. Navy ground #000c18 to #001a33, document sheet a lifted navy, one cyan #00d2ff for numbers, active tab and focus only. Montserrat 800 for numerals and titles, Inter for text. Person colours mark comment authors. Light theme = cool paper with navy ink, same cyan role.

STORY: enter the password, say who you are, see the contents with what is new and how much feedback each section has, open a section, read, tap a passage to add a note in the margin, answer others, resolve. David pulls everything back into Markdown.

FIRST VIEWPORT: Home: slim top bar (logo, "Návrhy 2027", viewer chip). Below it the contents list owns the screen: per row a large Montserrat numeral 01-07, section title, one-line purpose, docs count, open comments, planned rows dimmed "připravuje se". Doc: breadcrumb, title, sibling docs as sub-tabs, ~70ch text column, 320px margin with notes aligned to their blocks, numbered divider tabs on the right edge.

FORM: Briefing book, position 3 of 7 on the ranked list (the roll's lead), seed: none (unavailable)

SIGNATURE: marginalia that align to their block and stack without overlap; Present mode (P) hides the margin, scales type, arrow keys step through H2 sections.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
